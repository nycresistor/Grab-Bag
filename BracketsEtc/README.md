## Light pole mounting bracket for sewing/crafting table

The two .3mf files are generated from the FreeCAD source. The checked
in version is as printed and installed. The bolt holes are all for M5
screws and nuts.

An M5 nut goes in the slot accessible from the bottom. Add some glue or
packing once the nut is installed to prevent it from falling out if
the clamping screw is competely removed. If you're modifying this in 
the future, consider just making a recess on the inside of the large bore
for inserting the nut instead.

### Files

* [FreeCAD source file](light_pole_support.FCStd)
* [Support bracket 3mf](light_pole_support_bracket.3mf)
* [Snap-on lever for clamping screw 3mf](light_pole_support_lever.3mf)

## Tooltown drawer handle

These are replacement handles for the metal drawers in the back of tooltown
that lack them. Two M5 bolts and nuts are needed to secure them. Holes will
need to be drilled in each drawer 120mm apart and 25-30mm from the bottom of
the drawer. The holes should be clearance holes for an M5 bolt, which means 5.5mm in diameter (or a bit larger).

### Files

* [FreeCAD source file](tooltown-drawer-handle.FCStd)
* [Drawer handle 3mf, 5 handles](tooltown-drawer-handle-5x.3mf)
