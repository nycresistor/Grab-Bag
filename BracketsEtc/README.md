## Light pole mounting bracket for sewing/crafting table

The two .3mf files are generated from the FreeCAD source. The checked
in version is as printed and installed. The bolt holes are all for M5
screws and nuts.

An M5 nut goes in the slot accessible from the bottom. Add some glue or
packing once the nut is installed to prevent it from falling out if
the clamping screw is competely removed. If you're modifying this in 
the future, consider just making a recess on the inside of the large bore
for inserting the nut instead.
